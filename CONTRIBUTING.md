# Contributing to S.C.O.U.T.

Thank you for your interest in contributing to S.C.O.U.T.!

## Guidelines

1. All contributions must adhere to the Apache License 2.0.
2. Every source file (.ino, .cpp, .h) must include the standard copyright header:
   ```cpp
   /*
    * Copyright 2026 Absolute Tech
    * Licensed under the Apache License, Version 2.0
    * Project: S.C.O.U.T. — Version v0.27.0 "OP"
    * File: [filename] · Purpose: [one-liner]
    */
   ```
3. Before submitting a pull request, ensure firmware builds cleanly with `pio run -e lolin32`.
