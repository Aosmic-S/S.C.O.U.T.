# Enclosure & 3D Printed Parts

The S.C.O.U.T. chassis housing is designed for post-disaster rugged environments.

## Component Layout
- **Lower Chassis**: Battery, L298N driver, TT gear motors, buck converter.
- **Upper Chassis**: ESP32 LOLIN32, Internal DHT11, MQ2 & MQ135 gas sensors.
- **External Mounts**: External DHT11, E88 FPV camera, active buzzer, onboard status LED window.
